## 🔥 Highlights (이번 주 가장 주목할 만한 3가지)

1. **LoCoSplat** (arXiv:2610.04351) — 무거운 3D 추론 네트워크를 버리고 포인트 클라우드 로컬 평균만으로 피드-포워드 3DGS를 단일 GPU에서 33ms에 처리. 실시간 피드-포워드 3D Gaussian Splatting의 효율성 기준을 새로 세운 논문.

2. **DeltaSplat** (arXiv:2610.09853) — 포즈 없이도 피드-포워드 3DGS가 가능하게 하는 반복적 잔차 정제 모듈. 파라미터 2.2% 추가로 PSNR 26.64 dB 달성, 포즈-프리 재구성의 실용화를 앞당기는 핵심 기여.

3. **GPS/IMU/LiDAR 타이틀리-커플드 SLAM** (arXiv:2609.20321) — FAST-LIO2 프론트엔드에 GTSAM 포즈그래프 백엔드를 결합해 자율주행 차량용 완성된 시스템 구현. SLAM 연구를 넘어 즉시 현장 적용 가능한 AV 레퍼런스 아키텍처 제시.

## 1. LiDAR SLAM / Sensor fusion

### 신규 논문 (arXiv)

- **[Implementation of Tightly-Coupled SLAM Fusion of GPS, IMU, and LiDAR for Autonomous Vehicles]** — Multiple authors. arXiv:2609.20321 (2026-09)
  https://arxiv.org/abs/2609.20321
  - Velodyne 3D LiDAR + 고주파 IMU + GPS를 타이틀리-커플드 방식으로 융합. FAST-LIO2 오도메트리와 GTSAM 루프 클로저 백엔드를 결합한 완성형 AV SLAM 아키텍처. 실차 검증까지 포함한 실용 구현 레퍼런스로 즉시 활용 가능.

- **[LXD-SLAM: LiDAR+X Dense SLAM with Configurable Sensor Combinations]** — Multiple authors. arXiv:2606.27811 (2026-06)
  https://arxiv.org/abs/2606.27811
  [catch-up] LiDAR를 필수 센서로, 카메라·IMU·휠 인코더·GNSS를 선택적으로 조합하는 $\binom{5}{i}$ 구성 가능한 Dense SLAM. 글로벌 일관성 있는 밀집 메쉬를 실시간 생성하며 공개 데이터셋에서 특화 방법론과 동급 성능 달성.

- **[Ultra-Fusion: A Resilient Tightly-Coupled Multi-Sensor Fusion SLAM Framework]** — Multiple authors. arXiv:2606.21223 (2026-06)
  https://arxiv.org/abs/2606.21223
  [catch-up] 도심 협곡·터널 등 센서 열화 환경에서 강인한 ITS용 SLAM. 슬라이딩 윈도우 추정기 기반의 비동기 멀티센서 퓨전으로 휠 오도메트리와 GNSS 보강까지 지원. 자율주행 인프라 적용을 겨냥한 실용 설계.

- **[Does Dynamic-Point Filtering Help When Texture Is Scarce?]** — Zekui Xue 외. arXiv:2610.10564 (2026-10-09, IROS 2026 제출)
  https://arxiv.org/abs/2610.10564
  - ORB-SLAM2 프론트엔드에서 동적 포인트 필터링이 저-텍스처 합성 실내 환경에 미치는 영향을 체계적으로 비교. 오픈소스 코드·데이터셋 공개. SLAM 벤치마킹 방법론에 실질적 기여.

## 2. Path planning / Motion planning

### 신규 논문 (arXiv)

- **[Learning-Based Motion Planning for Dynamic Environments: From Foundational Algorithms to Emerging Paradigms]** — Multiple authors. arXiv:2608.00625 (2026-08-01)
  https://arxiv.org/abs/2608.00625
  - 동적 환경용 학습 기반 모션 플래닝의 포괄적 서베이. 강화학습·모방학습·확산 모델·MPC 워밍 등 주요 패러다임과 nuPlan·Waymo Open Motion 등 벤치마크에서의 성능 비교. 진입자에게 최적의 로드맵 논문.

- **[Motion Planning with Model-Based Diffusion via Constraint Optimization and Adaptive Scheduling]** — Multiple authors. arXiv:2607.14455 (2026-07)
  https://arxiv.org/abs/2607.14455
  - 비볼록(non-convex) 환경에서 안전 제약을 확산 스케줄에 적응적으로 적용하는 단일 로봇 플래너. 학습된 사전(prior)과 물리 제약의 균형을 자동 조율해 실패 없는 경로 생성 성공률을 크게 향상.

- **[SGTP: Sampling-based Game-Theoretic Planning for Real-Time Multi-Vehicle Autonomous Racing]** — Multiple authors. arXiv:2607.25388 (2026-07)
  https://arxiv.org/abs/2607.25388
  - 멀티 에이전트 자율 레이싱 시나리오에서 게임이론 기반 샘플링 플래너로 실시간 상호작용 경쟁 주행 구현. AV 고속 합류·추월 시나리오 연구에 직접 적용 가능한 프레임워크.

- **[NeurRAFT: Robot Motion Planning via Anchor-Level Flow Matching with Clearance-Aware Preference Tuning]** — Multiple authors. arXiv:2608.24026 (2026-08)
  https://arxiv.org/abs/2608.24026
  - 플로우 매칭(Flow Matching)을 앵커 레벨로 분해하고 여유공간(clearance) 인식 선호 튜닝으로 충돌 회피를 강화. 로봇 팔 조작 플래닝에서 기존 확산 기반 방법 대비 우수한 클리어런스 마진 달성.

- **[Simulation-Informed Diffusion for Decentralized Multi-Robot Motion Planning]** — Multiple authors. arXiv:2605.27697 (2026-05)
  https://arxiv.org/abs/2605.27697
  [catch-up] 분산 멀티로봇 플래닝에서 제약-인식 확산 모델로 이웃 궤적을 예측해 필요할 때만 조율 트리거. 고밀도 혼잡 환경에서 충돌률 최소화, 멀티 AMR 물류창고 적용 가능성 높음.

## 3. 3D Reconstruction / Scanning

### 신규 논문 (arXiv)

- **[LoCoSplat: Real-Time Feed-Forward 3D Gaussian Splatting with Minimal 3D Reasoning]** — Multiple authors (Georgia Tech). arXiv:2610.04351 (2026-10-03)
  https://arxiv.org/abs/2610.04351
  - 학습된 3D 네트워크 대신 포인트 클라우드 주변 앵커의 로컬 평균을 활용. 6뷰 장면을 단일 GPU에서 33ms 처리. RealEstate10K 6/12/24뷰 모두에서 선행 피드-포워드 방법 능가. 실시간 3DGS의 새로운 효율성 기준.

- **[DeltaSplat: Iterative Gaussian Refinement for Pose-Free Feed-Forward 3D Gaussian Splatting]** — Multiple authors. arXiv:2610.09853 (2026-10-07)
  https://arxiv.org/abs/2610.09853
  - 포즈-프리 피드-포워드 3DGS에 잔차(delta) 정제 모듈 추가. 렌더링 뷰 + Plücker 광선 + 깊이로 Gaussian을 반복 보정. 파라미터 2.2% 증가로 DL3DV에서 26.64 dB PSNR 달성. 포즈 정보 없이도 고품질 재구성 실용화를 앞당김.

- **[TileSkipper: Region-Adaptive Tile Pruning for 3D Gaussian Splatting]** — Multiple authors (Arizona State University). arXiv:2610.09343 (2026-10-07)
  https://arxiv.org/abs/2610.09343
  - 장면 전체에 단일 타일-열거 임계값 대신 각 Gaussian마다 적응적 컷오프 부여. 13개 장면에서 평균 1.088× 속도향상, PSNR 변화 -0.007 dB. 3DGS 래스터화 최적화의 실용적 기여.

- **[AI-based Single-Shot Structured-Light Depth Reconstruction for Real-Time Laparoscopic Surgical Guidance]** — Wayne Wonseok Rodgers 외. arXiv:2608.05109 (2026-08-05)
  https://arxiv.org/abs/2608.05109
  - AI 기반 단일 샷 구조광으로 복강경 수술 실시간 깊이 재구성. eess.IV + 로봇공학·광학 크로스리스팅. 의료 3D 스캐닝에서 구조광+딥러닝 융합의 선도 사례.

- **[Need for Speed: Zero-Shot Depth Completion with Single-Step Diffusion]** — Multiple authors. arXiv:2603.10584 (2026-03)
  https://arxiv.org/abs/2603.10584
  [catch-up] 단일 스텝 확산 모델로 제로-샷 깊이 완성. 추가 파인튜닝 없이 미지의 장면에 일반화. ToF·LiDAR 스파스 깊이 보강 파이프라인에 즉시 통합 가능.
