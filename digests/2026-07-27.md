## 1. LiDAR SLAM / Sensor fusion

### 신규 논문 (arXiv)

- **[catch-up] Ultra-Fusion: A Resilient Tightly-Coupled Multi-Sensor Fusion SLAM Framework under Sensor Degradation and Spatiotemporal Perturbation for Intelligent Transportation Systems** — 복수 중국 대학 공동 연구팀 (Beijing Institute of Technology, Chongqing Univ, SJTU 外). arXiv:2606.21223 · https://arxiv.org/abs/2606.21223
  - WIO·VIO·LIO·LVIO 모드를 단일 unified sliding-window estimator로 통합하고, Observability-Aware 초기화 및 Factor-Wise 신뢰도 스케줄링을 적용. GNSS 음영·LiDAR 퇴화·조명 열화 등 복합 고장 시나리오에서 강건성을 실증. 자율차·사족보행 로봇·UAV 등 ITS 전 분야 대상. 코드 포함 GitHub 공개.

- **[catch-up] DSP-SLAM++: A Unified Framework for Multi-Class, High-Fidelity Object SLAM in the Wild** — Kourani et al. (American Univ of Beirut). arXiv:2606.25953 · https://arxiv.org/abs/2606.25953
  - 단안 어안-LiDAR 센서 쌍을 위해 DSP-SLAM을 재설계. 비동기 매핑 파이프라인으로 실시간성을 확보하면서 여러 객체 클래스에 대해 고품질 3D 형상을 병렬 생성. 최대 객체 처리 지연을 SOTA 대비 70% 절감. 자율주행·로봇 조작 분야 실용화 경로 제시. 오픈소스(github.com/AUBVRL/DSP-SLAMpp).

- **[catch-up] BIEVR-LIO: Robust LiDAR-Inertial Odometry through Bump-Image-Enhanced Voxel Maps** — Pfreundschuh et al. arXiv:2604.14421 (v2 업데이트: 2026-07-02) · https://arxiv.org/abs/2604.14421
  - 표면 "bump 이미지"를 활용해 기하학적 정보가 풍부한 영역에 등록 포인트를 집중시키는 map-informed 샘플링 전략. 교차로·비정형 지형 등 특징 희소 환경에서 LIO 견고성 향상. 최근 v2 개정판 공개.

### OSS 릴리즈 / GitHub trending

- **GeoGS-SLAM** — ICRA 2026 채택 논문, 코드 공개. Geometric Prior를 활용한 온라인 Monocular 3D Gaussian Splatting SLAM.
  - 기하학적 사전 정보로 Gaussian 초기화를 안정화해 단안 카메라만으로도 일관된 포토리얼리스틱 3D 맵 생성 가능. 실시간 성능 유지.

- **FAST-LIO-SAM 생태계** — `lidar-inertial-odometry` GitHub 토픽 지속 활성. FAST-LIO2 + LIO-SAM 루프 클로징 결합 구현체(engcang/FAST-LIO-SAM) 및 주요 SLAM 알고리즘 비교 레포(engcang/SLAM-application)가 커뮤니티 핵심 참조 자료로 유지됨.

### 블로그 / 산업 동향

- **[catch-up] NVIDIA R²D²: Building AI-based 3D Robot Perception and Mapping** · https://developer.nvidia.com/blog/r2d2-building-ai-based-3d-robot-perception-and-mapping-with-nvidia-research/
  - NVIDIA Research의 통합 로봇 인식 스택 공개. FoundationStereo(깊이 추정), PyCuVSLAM(비주얼 SLAM), BundleSDF(6DOF 자세 추정), nvblox PyTorch Wrapper(실시간 3D 재구성)를 모듈 조합 방식으로 구성. Isaac Perceptor 플랫폼 기반 엔드투엔드 파이프라인으로 AMR·조작 로봇에 직접 적용 가능.

## 2. Path planning / Motion planning

### 신규 논문 (arXiv)

- **[이번 주] Cognitive Dual-Process Planning for Autonomous Driving with Structured Scene Knowledge and Verifiable Reasoning-Action Consistency** — Ye et al. (Beijing Institute of Technology & Southeast Univ). arXiv:2607.19194 · https://arxiv.org/abs/2607.19194
  - VLM의 고비용 추론을 일상 장면에서 생략하고 복잡 상황에서만 깊은 추론을 활성화하는 자율주행 이중 처리 플래너. 구조화된 S-CoT 스키마와 자동 데이터 엔진을 결합해 수동 레이블 없이 고품질 감독 신호 생성. 추론-행동 일관성 검증 레이어를 통해 VLM 환각으로 인한 위험 행동 차단. 7월 21일 제출, 이번 주 가장 신선한 논문.

- **[catch-up] SPADE: Sketch-guided Path Planning Augmented with Diffusion Experts** — Hana et al. arXiv:2606.03512 · https://arxiv.org/abs/2606.03512
  - 사용자 스케치를 조건으로 확산 전문가 모델(Diffusion Expert)이 AMR 경로를 생성. 경량 행동 복제 모델과 결합해 SKIPP 대비 APE 39.1%, FID 33.5% 개선, 학습 파라미터 93.8% 절감. 직관적 HRI(인간-로봇 상호작용) 방식으로 경로 지정이 가능해 산업 현장 적용성 높음.

- **[catch-up] Generative Multi-Robot Motion Planning via Diffusion Modeling with Multi-Agent Reinforcement Learning Guidance** — Lee, Mutta, Ko (Arizona State Univ & Mississippi State Univ). arXiv:2606.00933 · https://arxiv.org/abs/2606.00933
  - 각 로봇이 단일 에이전트 확산 모델로 후보 궤적을 독립 생성하고, MARL 기반 중앙 가치함수가 역확산 과정을 경사 조정해 충돌 억제. 제너레이티브 모델 재학습 없이 다중 로봇 조율 달성. 지수 tilting 공식으로 비중앙화 플래닝과 협력 조율을 우아하게 통합.

- **[catch-up] Motion Planning for Autonomous Vehicles using Optimization over Graphs of Convex Sets** — arXiv:2605.14199 · https://arxiv.org/abs/2605.14199
  - 볼록 집합 그래프 위 최적화(GCS)를 자율차 모션 플래닝에 적용. 위상 및 시간적 복잡성을 혼합 정수 프로그래밍 없이 처리, 실시간 계획 가능성 확보.

  - Google DeepMind Genie 3를 AV 도메인에 특화 적용한 세계 모델. 실제 주행 데이터로부터 포토리얼리스틱 인터랙티브 3D 환경을 생성해 플래너 검증용 시뮬레이션 병목 해소. Waymo 공개 데이터셋 + NuRec 툴킷으로 커뮤니티 활용 가능.

## 3. 3D Reconstruction / Scanning

### 신규 논문 (arXiv)

- **[catch-up] SurfaceSplat: Connecting Surface Reconstruction and Gaussian Splatting** — 복수 저자. arXiv:2507.15602 · https://arxiv.org/abs/2507.15602
  - SDF가 전역 기하를 포착해 3DGS의 포인트 클라우드 초기화를 개선하고, 개선된 3DGS가 새로운 시점 이미지를 생성해 SDF의 세부 표면을 정교화하는 양방향 피드백 구조. DTU·MobileBrick 벤치마크에서 표면 재구성 및 Novel View Synthesis 모두 SOTA 달성. Sparse-view 고품질 재구성 실용화의 새 기준.

- **[catch-up] Sparse-View 3D Reconstruction: Recent Advances and Open Challenges** — arXiv:2507.16406 · https://arxiv.org/abs/2507.16406
  - Sparse-view 3D 재구성 분야 포괄 서베이. NeRF 기반, 3DGS 기반, Diffusion Prior 활용 기법을 체계적으로 정리하고 Geometric Regularization·Generative Prior·Foundation Model 통합 전략의 장단점 분석. 연구 진입점 및 문헌 지도로 유용.

- **[catch-up] Leveraging NeRF-Rendered Images for 3D Gaussian Splatting** — arXiv:2606.09034 · https://arxiv.org/abs/2606.09034
  - 도로 장면(street-scene) 렌더링에서 3DGS의 속도와 NeRF의 품질을 동시에 달성. NeRF가 추가 학습 이미지를 생성해 3DGS 최적화 과정을 안정화하는 방식으로, 두 패러다임의 시너지를 현실적인 AV 데이터셋에서 입증.

### OSS 릴리즈 / GitHub trending

- **COLMAP 4.1.1** — 2026-07-17 릴리즈 · https://colmap.github.io/changelog.html
  - SfM 표준 라이브러리의 마이너 버그픽스. GUI 시작 시 매퍼 데이터베이스의 불필요한 중복 로딩을 지연 로딩(lazy loading)으로 개선, 대형 프로젝트에서 초기화 속도 향상. UI 아이콘 팔레트 틴팅 추가. 안정성·UX 개선 위주 릴리즈.

- **MAGiSt3R & Spark3R** — ECCV 2026 채택, GitHub trending
  - **MAGiSt3R** (Multi-Agent Feed-forward 3D Reconstruction): 멀티 에이전트 방식으로 모노큘러 RGB 비디오에서 실시간 3D 재구성. **Spark3R** (Asymmetric Token Reduction): 비대칭 토큰 리덕션으로 피드포워드 3D 재구성 속도를 대폭 향상. 두 논문 모두 Transformer 기반 초고속 재구성의 새 기준점으로 평가받으며 코드 공개 예정.

- **ParkGaussian** — arXiv 2026, GitHub trending
  - 서라운드뷰 카메라 기반 자율주차 환경의 3DGS 재구성에 특화. AV 실내 주차 환경 3D 맵 구축 분야에서 주목.

### 블로그 / 산업 동향

- **[catch-up] NVIDIA GTC 2026 — Bridging the Real-to-Sim Gap with 3D Gaussian Splatting** · https://www.nvidia.com/gtc/session-catalog/sessions/gtc26-cwes81600/
  - 실제 환경 데이터를 3DGS로 재구성해 로봇 학습용 시뮬레이터로 활용하는 Real-to-Sim 파이프라인 세션. Sim-to-Real gap 최소화 전략과 NVIDIA Isaac Sim과의 통합 방법 제시. 로봇 정책 학습 인프라 관점에서 중요한 산업 트렌드.
