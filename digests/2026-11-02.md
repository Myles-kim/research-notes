## 1. LiDAR SLAM / Sensor fusion

### 신규 논문 (arXiv)

- **[Implementation of Tightly-Coupled SLAM Fusion of GPS, IMU, and LiDAR for Autonomous Vehicles](https://arxiv.org/abs/2609.20321)** — (arXiv:2609.20321, Sep 2026) [catch-up]
  - Velodyne 3D LiDAR + 고주파 IMU + 1 Hz GPS를 Iterated Error-State Kalman Filter(IESKF)로 타이트하게 결합. GPS 신호 세기에 따른 적응적 노이즈 가중치(1.0–5.0 m)가 특징. FAST-LIO2 파이프라인을 3D로 확장한 실용적 구현체.

- **[LXD-SLAM: LiDAR+X Dense SLAM with Configurable Sensor Combinations](https://arxiv.org/abs/2606.27811)** — (arXiv:2606.27811, Jun 2026) [catch-up]
  - 3D LiDAR를 중심축으로 카메라·IMU·휠 엔코더·GNSS를 32가지 조합(C(5,0)~C(5,5))으로 플러그앤플레이 지원. 센서 구성 유연성이 필요한 현장 로봇 연구에 적합.

- **[Ultra-Fusion: Resilient Tightly-Coupled Multi-Sensor Fusion SLAM](https://arxiv.org/abs/2606.21223)** — (arXiv:2606.21223, Jun 2026) [catch-up]
  - 열악한 조명, LiDAR 퇴화, GNSS 단절 상황에서도 강인한 SLAM 프레임워크. 지능형 교통 시스템(ITS) 적용을 타깃으로 하며, 센서 시공간 노이즈 처리가 핵심.

- **[FAR-LIO: Enabling High-Speed Autonomy through Fast, Accurate, and Robust LiDAR-Inertial Odometry](https://arxiv.org/pdf/2606.26010)** — (arXiv:2606.26010, Jun 2026) [catch-up]
  - CUDA 기반 voxel hashmap(적응적 밀도)으로 GICP 전단부 가속화, 지연 보상 EKF 후단부 결합. 자율 레이싱카 하드웨어에서 검증. 평균 위치 오차 6.9% 감소·런타임 38.4% 단축. 코드 오픈소스 공개.

## 2. Path planning / Motion planning

### 신규 논문 (arXiv)

- **[NMPP: Nonlinear Model Predictive Planning for Agile UAV Flight in Cluttered Environments](https://arxiv.org/abs/2610.08695)** — (arXiv:2610.08695, Oct 6, 2026)
  - 쿼드로터가 장애물이 밀집한 환경을 고속으로 통과하기 위해 감지된 장애물을 하드 기하 제약으로 처리하는 비선형 MPC 계획기. 선형 MPC 대비 위치 RMSE 58–67% 감소. 실제 드론 적용 가능성 높음.

- **[Integrating Flow Matching and Model Predictive Control for Safe Robot Navigation](https://arxiv.org/abs/2610.29377v1)** — (arXiv:2610.29377, Oct 21, 2026)
  - 흐름 매칭(Flow Matching) 기반 경로 생성과 MPC를 결합한 일반 로봇 내비게이션. 이벤트 기반 재계획으로 미지의 동적 장애물 환경에서도 충돌 없는 주행 달성. 드론 외 지상 로봇·로봇 팔로 확장 가능한 범용 구조.

- **[OA-MPPI: Occlusion-Aware Model Predictive Path Integral Control for UAV Flight](https://arxiv.org/abs/2609.28709)** — (arXiv:2609.28709, Sep 23, 2026) [catch-up]
  - 가려진(occluded) 공간을 명시적으로 고려하는 MPPI 제어기. 예측 불가 장애물을 안전하게 회피하며 고속 UAV 비행 가능. 샘플 기반 MPPI의 점유 불확실성 처리를 확장.

- **[Risk-Aware Motion Planning with Learned Trajectory Primitives](https://arxiv.org/abs/2607.26802)** — (arXiv:2607.26802, Jul 2026) [catch-up]
  - 학습된 궤적 프리미티브와 확률적 충돌 평가를 결합하고, 최적화 기반 정제까지 연결하는 도심 자율주행용 리스크 인지 계획기. 데이터 기반과 수리 최적화의 하이브리드 구조.

- **[Learning-Based Motion Planning for Dynamic Environments: Survey](https://arxiv.org/abs/2608.00625)** — (arXiv:2608.00625, Aug 2026) [catch-up]
  - 동적 환경 학습 기반 계획을 ① 직접 정책 학습 ② 학습-강화 고전 계획 ③ 하이브리드 ④ 훈련 강화로 분류한 서베이. 최신 LLM·Diffusion 기반 계획 패러다임도 커버.

## 3. 3D Reconstruction / Scanning

### 신규 논문 (arXiv)

- **[X-Splat: Unified Gaussian Splatting for Joint RGB and X-ray 3D Reconstruction](https://arxiv.org/abs/2610.23237)** — (arXiv:2610.23237, Oct 2026, **SIGGRAPH Asia 2026**)
  - RGB와 X-ray 데이터를 공유 Gaussian 기하 표현으로 통합해 멀티모달 3D 재건 수행. 의료·산업 CT 검사와 시각적 3D 재건을 단일 파이프라인으로 처리 가능. SIGGRAPH Asia 2026 채택으로 품질 검증.

- **[Gaussian Splatting for Real-Time Scene Reconstruction: Methods, Systems, and Trade-offs](https://arxiv.org/abs/2610.17513)** — (arXiv:2610.17513, Oct 13, 2026)
  - 3D Gaussian Splatting 분야를 ① 단일 뷰 생성 ② 동적 표현 ③ SLAM ④ 압축/경량화 ⑤ 에디팅 5개 패밀리로 정리한 서베이. 실시간 운용을 위한 시스템 설계 트레이드오프 분석 포함. 새로 진입하는 연구자에게 필독 자료.

- **[OX-NeRF: 3D X-ray Tomography Reconstruction from Sparse Views Using Implicit Neural Representation](https://arxiv.org/abs/2610.11547)** — (arXiv:2610.11547, Oct 8, 2026)
  - 희소 X-ray 뷰에서 신경 암묵 표현(NeRF)으로 3D 단층 촬영 재건. 크로스 씬 특징 학습과 해시 격자 최적화를 결합해 기존 NeRF 대비 희소 뷰 정확도 향상. 의료 영상·비파괴 검사 응용 가능.

- **[Federated 3D Gaussian Splatting for Large-Scale Scene Reconstruction at Wireless Edge](https://arxiv.org/abs/2609.32177)** — (arXiv:2609.32177, Sep 26, 2026) [catch-up]
  - 대규모 장면을 여러 엣지 기기에 분산해 3DGS 모델을 연합 학습(Federated Learning) 방식으로 훈련하는 자원 효율적 프레임워크. 도시 스케일 디지털 트윈 구축에 적용 가능성.

- **[MotionGS-SLAM: Event-Modulated Gaussian Splatting for Motion-Blur Robust SLAM](https://arxiv.org/pdf/2608.15024)** — (arXiv:2608.15024, Aug 2026) [catch-up]
  - 이벤트 카메라 데이터로 모션 블러를 보정하는 3DGS SLAM. 추적 전단과 맵핑 후단으로 구성되며, 고속 이동 환경에서의 강인성 향상. 이벤트+3DGS 융합 트렌드의 최신 사례.
