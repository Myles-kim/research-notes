## 🔥 Highlights (이번 주 가장 주목할 만한 3가지)

1. **TRaIL-Odom** (arXiv:2609.03561) — Radar·IMU·LiDAR를 연속 시간 프레임에서 타이트하게 융합하고 퇴화 환경에서 Doppler 잔차를 적응적으로 재가중치하여 기하 퇴화 시퀀스의 ATE RMSE를 86% 감소. 레이더를 3번째 LiDAR 보조 센서로 격상한 의미 있는 설계.

2. **LightSplat** (arXiv:2609.07274, IROS 2026) — 3D Gaussian Splatting 기반 RGB-D SLAM에 실시간 루프 클로저를 추가한 최초의 실용 구현. 평균 8 FPS를 유지하면서 포즈 그래프 최적화로 전역 일관성 확보. GitHub MIT 라이선스 공개.

3. **Dual Process Motion Planning** (arXiv:2609.01260) — "빠른 직관(System 1) vs. 느린 추론(System 2)" 이중 프로세스를 로봇 플래닝에 이식한 뉴로심볼릭 프레임워크. 다양한 비선형 벤치마크에서 효율·정확도·일반화 동시 향상, 학습 기반과 기호 기반 접근의 융합 가능성을 실증.

## 1. LiDAR SLAM / Sensor fusion

### 신규 논문 (arXiv)

- **[TRaIL-Odom: Tightly Coupled Continuous Time Radar-IMU-LiDAR Odometry with Adaptive Doppler Weighting]**
  arXiv:2609.03561 (2026-09-03)
  https://arxiv.org/abs/2609.03561
  - 기존 Radar-LiDAR 융합은 고정 잔차 가중치를 사용해 퇴화 환경에서 취약했다. 본 논문은 연속 시간 추정 프레임워크에서 두 가지 퇴화 인식 Doppler 재가중치 모듈(포인트별 + 스캔별 gain scheduling)을 제안. 13개 시퀀스 평가에서 SOTA 달성, 기하 퇴화 3시퀀스에서 ATE RMSE −86.0%, RTE −78.5%. 터널·주차장 등 LiDAR 취약 환경에 레이더를 적극 활용하는 설계로 산업 현장 적용성이 높다.

- **[Implementation of Tightly-Coupled SLAM Fusion of GPS, IMU, and LiDAR for Autonomous Vehicles]**
  arXiv:2609.20321 (2026-07-31)
  https://arxiv.org/abs/2609.20321
  - Velodyne 3D LiDAR·고주파 IMU·GPS를 IESKF(Iterated Error-State Kalman Filter)로 타이트하게 결합한 AV용 SLAM. FAST-LIO2를 3D 백엔드로 사용하며 2D 기준 구현 → 3D 단계적 검증 방법론을 제시. 도심 캐니언·대칭 환경의 개별 센서 맹점을 상호 보완, HD 맵 수준의 포인트 클라우드 생성.

- **[LightSplat: Real-Time High-Fidelity 3D Gaussian SLAM with Loop Closure]** — Junze Bao et al.
  arXiv:2609.07274 (2026-09-07) — **IROS 2026 accepted**
  https://arxiv.org/abs/2609.07274
  - 하이브리드 표현(희소 특징 + 밀집 Gaussian 서브맵)으로 빠른 추적과 고품질 재구성을 동시에 달성. 온라인 루프 클로저를 특징 가속 3DGS 등록으로 구현, 포즈 그래프 최적화로 전역 일관성 유지. 평균 8 FPS 실시간 처리, 실제 로봇 플랫폼 검증 완료. 코드 MIT 라이선스 공개.

- **[Ultra-Fusion: A Resilient Tightly-Coupled Multi-Sensor Fusion SLAM Framework under Sensor Degradation and Spatiotemporal Perturbation for ITS]**
  arXiv:2606.21223 (2026-06-26) [catch-up]
  https://arxiv.org/abs/2606.21223
  - ITS(지능형 교통 시스템) 환경에서 센서 퇴화와 시공간 섭동에 강인한 다중 센서 융합 SLAM. GTSAM 포즈 그래프 최적화 기반 멀티모달 루프 클로저로 개별 센서 맹점 극복. V2X·도심 AV 인프라 연구자에게 실용적 참조 프레임워크 제공.

## 2. Path planning / Motion planning

### 신규 논문 (arXiv)

- **[Dual Process Motion Planning]** — Jiayi Yan, Francesco Fabiano, Alessandro Abate.
  arXiv:2609.01260 (2026-09-01)
  https://arxiv.org/abs/2609.01260
  - Daniel Kahneman의 이중 시스템 이론("빠른 직관 vs. 느린 추론")을 로봇 비선형 모션 플래닝에 이식. 기호 솔버(System 2)와 경험 기반 학습 모듈(System 1)을 메타인지 컨트롤러로 동적 조율. 다양한 비선형 벤치마크에서 계획 효율·정확도·일반화 동시 향상. 태스크 간 경험 재사용으로 확장성 있는 플래닝 패러다임 제시.

- **[SRMP: Search-Based Robot Motion Planning Library]**
  arXiv:2509.25352 (2025-09-29) [catch-up]
  https://arxiv.org/abs/2509.25352
  - 멀티 로봇 매니퓰레이션용 탐색 기반 플래닝 라이브러리 최초 공개. MuJoCo·Sapien·Genesis·PyBullet 통합 Python/C++ API 제공. 이론적 보장(완전성·최적성) 기반으로 일관되고 반복 가능한 경로를 생성, 산업 안전 및 로봇 학습 데이터셋 구축에 직결. https://srmp.readthedocs.io

- **[Search-Based Spatiotemporal and Multi-Robot Motion Planning on Graphs of Space-Time Convex Sets]**
  arXiv:2607.00444 (2026-07) [catch-up]
  https://arxiv.org/abs/2607.00444
  - GCS(Graphs of Convex Sets) 프레임워크를 시공간 다중 로봇 플래닝으로 확장. 볼록 집합 위 탐색 기반 방법과 연속 최적화의 장점을 결합해 고차원 멀티 로봇 충돌 회피 경로를 효율적으로 생성.

- **[Motion Planning with Model-Based Diffusion via Constraint Optimization and Adaptive Scheduling]**
  arXiv:2607.14455 (2026-07) [catch-up]
  https://arxiv.org/abs/2607.14455
  - 확산 모델 기반 플래닝에 제약 최적화와 적응형 스케줄링을 통합. 샘플링 기반 방법의 유연성과 제약 만족의 신뢰성을 동시에 확보하는 하이브리드 접근법. 조작 및 이동 로봇 태스크에서 성능 개선 확인.

## 3. 3D Reconstruction / Scanning

### 신규 논문 (arXiv)

- **[CGS-SLAM: Collaborative Gaussian Splatting based SLAM for Multi-Agent Reconstruction]**
  arXiv:2608.26868 (2026-08-27)
  https://arxiv.org/abs/2608.26868
  - RGB+IMU만으로 복수 에이전트가 분산-중앙 혼합 방식으로 3DGS 기반 공동 3D 재건을 수행하는 최초 구현. 각 에이전트는 메트릭 단안 깊이 추정기(Depth Pro)로 스케일 일관 서브맵을 생성하고, 서버에서 희소 재건 모델을 이용해 전역 정렬. GNSS 불가 환경에서 팀 로봇의 실시간 공간 인식을 가능하게 하는 실용적 아키텍처.

- **[Hilti-Trimble-Oxford Dataset: 360 Visual-Inertial Benchmark with Floor Plan Priors for SLAM and Localization]**
  arXiv:2607.06464 (2026-07) [catch-up]
  https://arxiv.org/abs/2607.06464
  - 건설 현장 특화 360° Visual-Inertial 데이터셋 논문. 인스타360 ONE RS 1인치(1472×1440, 30 Hz)와 1000 Hz IMU로 구성. 도면(Floor Plan) 기반 로컬라이제이션 카테고리를 별도 운영해 실내 정밀 위치 추정 평가 가능. 업계(Hilti·Trimble)와 학계(Oxford)의 공동 벤치마크 구축이라는 점에서 향후 표준 데이터셋 지위 기대.

- **[Leveraging NeRF-Rendered Images for 3D Gaussian Splatting]**
  arXiv:2606.09034 (2026-06-08) [catch-up]
  https://arxiv.org/abs/2606.09034
  - NeRF로 렌더링한 가상 뷰를 3DGS 학습에 추가 입력으로 활용해 가우시안 초기화 품질 향상. 도심 도로 장면에서 3DGS 렌더링 품질을 유지하면서 NeRF의 세밀한 기하 표현력을 흡수. NeRF와 3DGS 하이브리드 연구의 실용적 방향을 제시.

- **[Shape-Prior-Based Point Cloud Completion for Single-Stage Fully Sparse 3D Object Detection]**
  arXiv:2606.00688 (2026-06) [catch-up]
  https://arxiv.org/abs/2606.00688
  - LiDAR 포인트 클라우드의 희소성과 불완전성이 3D 물체 감지 정확도를 제한하는 문제에 대해, 형상 사전(Shape Prior) 기반 포인트 클라우드 보완을 단일 단계 희소 검출기에 통합. 자율주행 3D 인식 파이프라인에서 포인트 클라우드 전처리의 중요성을 재조명.
