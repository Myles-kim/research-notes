## 1. LiDAR SLAM / Sensor fusion

### 신규 논문 (arXiv)

- **[Implementation of Tightly-Coupled SLAM Fusion of GPS, IMU, and LiDAR for Autonomous Vehicles](https://arxiv.org/abs/2609.20321)** — arXiv:2609.20321
  - Velodyne 3D LiDAR + 고주파 IMU + GPS를 IESKF(Iterated Error-State Kalman Filter)로 긴밀히 결합하고, GTSAM 포즈 그래프를 백엔드로 활용해 다중 루프 클로저를 수행하는 실구현 사례. FAST-LIO2 기반 3D 아키텍처로 업그레이드한 2단계 개발 방법론이 인상적이며, 도심 GPS 음영·터널 등 현실 열악 환경에서의 robustness 검증 결과를 포함하고 있어 실용적 참고 가치가 높다.

- **[Ultra-Fusion: A Resilient Tightly-Coupled Multi-Sensor Fusion SLAM Framework under Sensor Degradation and Spatiotemporal Perturbation for Intelligent Transportation Systems](https://arxiv.org/abs/2606.21223)** — arXiv:2606.21223 `[catch-up]`
  - WIO/VIO/LIO/LVIO를 단일 슬라이딩 윈도우 추정기에서 통합하고 휠/GNSS를 옵셔널 팩터로 추가하는 구조. 조명 악화, LiDAR degeneracy, 바퀴 미끄러짐, GNSS 단절 등 다양한 센서 열화 시나리오에서 모두 동작하도록 설계되어, 자율주행 ITS 분야의 멀티센서 퓨전 실용 표준 프레임워크가 될 가능성이 있다. GitHub 코드 공개 중: [sjtuyinjie/Ultra-Fusion](https://github.com/sjtuyinjie/Ultra-Fusion).

- **[SLAMSqueezeBench: Comparing SLAM Systems under Resource Constraints](https://arxiv.org/abs/2609.19533)** — arXiv:2609.19533
  - 엣지 하드웨어에서 SLAM 시스템 9종(고전적·학습 기반·GS 기반 포함)을 compute/메모리 제약 환경 아래 프레임 드롭까지 시뮬레이션해 비교하는 벤치마크 프레임워크. 실제 배포 환경과 논문 성능 간의 간극을 직접 측정하는 첫 통합 벤치마크로, 엣지 로봇·드론 적용 시 시스템 선택 기준에 중요한 참고가 된다.

## 2. Path planning / Motion planning

### 신규 논문 (arXiv)

- **[NeurRAFT: Robot Motion Planning via Anchor-Level Flow Matching with Clearance-Aware Preference Tuning](https://arxiv.org/abs/2608.24026)** — arXiv:2608.24026
  - 빽빽한 장애물 환경에서의 매니퓰레이터 충돌 회피 경로 계획에 Flow Matching 기법을 적용. 밀집 웨이포인트 시퀀스 대신 압축된 '앵커' 웨이포인트만을 생성하고, Jacobian 가중 손실로 Task-space 영향력을 반영한다. 추론 시 두 번의 적분 스텝 + 3차 스플라인 보간으로 고해상도 궤적을 복원하며, 기존 신경 기반 플래너 대비 계산 효율과 안전여유(clearance)가 개선되었다. Texas A&M 팀 작업.

- **[SRMP: Search-Based Robot Motion Planning Library](https://arxiv.org/abs/2509.25352)** — arXiv:2509.25352 `[catch-up]`
  - 다중 로봇 매니퓰레이션 모션 플래닝을 최초로 최적성 보장과 함께 해결하는 소프트웨어 라이브러리. MuJoCo, Sapien, Genesis, PyBullet과 Python/C++ API로 통합되며 MoveIt! 플러그인도 제공해 하드웨어 배포까지 직결된다. 문서: [srmp.readthedocs.io](https://srmp.readthedocs.io/).

- **[Arborist: Algorithm-Hardware Co-Design for Fast and Efficient Motion Planning](https://arxiv.org/abs/2609.13420)** — arXiv:2609.13420
  - Fast Marching Tree*(FMT*) 알고리즘의 트리 간 병렬성을 안전하게 활용하는 알고리즘 혁신과, KD-tree 서브시스템·Look-ahead Planning Engine을 갖춘 전용 ASIC(ArboristAccel)을 결합. 16nm에서 500MHz 동작 시 기존 FMT* ASIC 대비 3.1× 전력 효율 달성. IEEE/ACM MICRO 2026 채택. 로봇 엣지 디바이스에서 실시간 고품질 경로 계획의 현실화 가능성을 크게 높였다.

- **[cuRoboV2: Dynamics-Aware Motion Generation with Depth-Fused Distance Fields for High-DoF Robots](https://arxiv.org/abs/2603.05493)** — arXiv:2603.05493 `[catch-up]`
  - NVIDIA 팀. B-스플라인 궤적 최적화(토크 제한 반영)와 GPU 네이티브 TSDF/ESDF 퍼셉션 파이프라인을 결합해 전체 작업 공간에 걸친 Dense signed distance field를 제공. SOTA 대비 최대 10× 빠르고 8× 메모리 절약, 99% collision recall. 고-DoF 로봇 팔에서 안전하고 반응적인 모션 생성의 새 기준을 제시한다.

## 3. 3D Reconstruction / Scanning

### 신규 논문 (arXiv)

- **[PanoGS-SLAM: Panoramic 3D Gaussian Splatting SLAM](https://arxiv.org/abs/2609.17387)** — arXiv:2609.17387
  - 파노라마 카메라(전방위 360°)에 특화된 최초의 3DGS SLAM 시스템. 구형 도메인에서 직접 Differentiable Rendering + 포즈 최적화를 수행하고, Equirectangular projection의 면적 왜곡을 보정하는 'Sphere-consistent photometric loss'와 Depth-guided Gaussian 초기화 전략을 도입. PALVIO·SynPano 벤치마크에서 기하 기반 및 GS 기반 베이스라인을 모두 능가하며 실시간 성능 달성. 좁은 FoV 핀홀 카메라의 한계를 넘어 SLAM 적용 범위를 전방위로 확장한다는 점에서 산업 응용 가치가 높다.

- **[CVT-GS: Learning to Simplify 3D Gaussian Splatting with Centroidal Voronoi Tessellation](https://arxiv.org/abs/2609.08730)** — arXiv:2609.08730
  - 훈련된 3DGS 씬을 재훈련·구조 변경 없이 사후(post-hoc) 압축하는 프레임워크. Geometry-aware CVT로 공간적으로 일관된 셀을 구성하고, 경량 신경망으로 각 셀의 대표 Gaussian을 Differentiable rendering 아래 예측. 기존 압축 기법들이 훈련 중 Pruning이나 Per-scene fine-tuning을 요구하는 한계를 극복해, 오프 더 셸프(off-the-shelf) 사전 훈련 모델에 바로 적용 가능하다는 것이 핵심 장점.

- **[From Fields to Splats: A Cross-Domain Survey of Real-Time Neural Scene Representations](https://arxiv.org/abs/2509.23555)** — arXiv:2509.23555 `[catch-up]`
  - Istituto Italiano di Tecnologia(IIT) 팀이 작성한 NeRF와 3DGS의 크로스 도메인 서베이. SLAM, 텔레프레전스, 로봇 매니퓰레이션, 3D 콘텐츠 생성 등 4개 도메인에서 양 표현법의 공통 목표(사실적 렌더링, 의미있는 3D 구조, 다운스트림 태스크)를 비교 분석. NeRF → 3DGS로의 전환 트렌드를 산업·연구 양 측면에서 체계적으로 정리한 레퍼런스 자료로 활용 가치가 높다.

- **[SLAMSqueezeBench (3D Reconstruction 측면)](https://arxiv.org/abs/2609.19533)** — arXiv:2609.19533
  - (Section 1에서도 언급) GS 기반 SLAM 시스템도 비교 대상에 포함해, 엣지 하드웨어 아래 3D 재구성 품질과 성능의 트레이드오프를 실측한다는 점에서 3D Reconstruction 커뮤니티에도 직접적 시사점을 제공.
