## 1. LiDAR SLAM / Sensor fusion

### 신규 논문 (arXiv) — 이번 주

- **[FREE-LIVO: Physically Decoupled Yet Tightly Coupled LiDAR-Inertial-Visual Odometry](https://arxiv.org/abs/2611.07463)** — arXiv:2611.07463, 제출 2026-11-05
  - LiDAR와 카메라 간 물리적 고정 장착 없이도 reprojection factor를 공유 factor graph에 통합해 타이트 커플링 성능을 달성. 멀티로봇·이기종 센서 환경에서 LiDAR-Visual 융합의 현장 적용 문턱을 크게 낮출 것으로 기대.

- **[A Tightly Coupled Magnetic-Inertial SLAM System for Field Robots](https://arxiv.org/abs/2611.03106)** — arXiv:2611.03106, 제출 2026-11-02
  - 9개 자력계 배열 + IMU로 카메라·LiDAR 없이 SLAM 수행. 분진·연기·저조도 등 극한 환경에서 VIO 대비 endpoint closure error를 최대 78% 절감. LiDAR 대체 솔루션이 아닌 보완 옵션으로서 주목할 만함.

- **[Not Losing Your Way: Mitigating VIO Drift via On-Demand Visual Feature Creation](https://arxiv.org/html/2611.07687v1)** — arXiv:2611.07687, 제출 2026-11-05
  - 항공 점검 드론용 VIO에서 텍스처 부족 구간에 대응하기 위해 필요 시 가상 특징점을 생성해 drift를 완화. 순수 VIO이지만 LiDAR 혼합 시 활용 가능한 feature management 아이디어 제공.

### 주목할 최근 논문 [catch-up]

- **[LXD-SLAM: LiDAR+X Dense SLAM with Configurable Sensor Combinations](https://arxiv.org/abs/2606.27811)** — arXiv:2606.27811, 2026-06-26
  - LiDAR를 핵심 센서로 두고 카메라·IMU·휠 엔코더·GNSS를 32가지 조합으로 구성 가능한 모듈형 SLAM. Gaussian Process sub-mesh 환경 모델 사용. 실험실이 아닌 필드 운용에서 센서 가용성이 가변적인 상황에 직접 대응하는 실용적 설계.

- **[Ultra-Fusion: Resilient Multi-Sensor SLAM for ITS](https://arxiv.org/abs/2606.21223)** — arXiv:2606.21223, 2026-06-19
  - 지능형 교통 시스템 대상. LiDAR 퇴화(featureless corridor 등), 휠 슬립, GNSS 단절을 동시에 처리하는 sliding-window 기반 타이트 커플링 프레임워크. 도심 자율주행 시나리오의 현실적 센서 장애 케이스를 망라.

### OSS 릴리즈 / GitHub

- **KISS-Matcher** — 2026-09-29 최신 업데이트. 빠른 포인트 클라우드 매칭 라이브러리로 SLAM 프론트엔드에 탑재 가능. GitHub topics/lidar-slam에서 활발히 사용 중.
- **COLMAP 4.2.1** — 2026-09-29 버그 픽스 릴리즈. meshing hang 및 global mapper regression 수정. 개발 빌드 4.3.0.dev0는 2026-11-01 기준 존재하나 공식 릴리즈 미확인. 다음 주 태그 주시 필요.

### 블로그 / 산업 동향

- **NVIDIA ICRA 2026 연구 포스트 (2026-11-05):** CMU·ETH Zurich·MIT 등 협력 대학팀의 약 50편 논문이 NVIDIA 가속 시뮬레이션·로봇 학습을 활용. 특히 PEEK(perception enhancement) 방법으로 sim-to-real 정확도 41× 향상 사례 보고. SLAM 및 로봇 위치추정 분야에 직접 활용 가능한 GPU 가속 파이프라인 주목.

## 2. Path planning / Motion planning

### 신규 논문 (arXiv) — 이번 주

이번 주(2611.xxxxx) 모션 플래닝 분야에서 주목할 만한 신규 제출은 아직 확인되지 않음. 아래는 10월 말~11월 초 기준 주목 논문.

### 주목할 최근 논문 (10월)

- **[Continuous-Time Motion Planning and Steering with Global Convergence](https://arxiv.org/abs/2610.30607)** — arXiv:2610.30607, 제출 2026-10-22
  - GlobMP: piecewise-polynomial 곡선에 대해 연속시간 충돌 제약을 그래디언트 투영으로 처리. 샘플링 기반 방법보다 궤적 품질이 우수하고, 전역 수렴 보장. 로봇 팔·드론 양쪽에 적용 가능한 범용 플래너로 주목.

- **[Enhancing Deep RL for Robotic Motion Planning via Task Decomposition](https://arxiv.org/abs/2610.35494)** — arXiv:2610.35494, 제출 2026-10월
  - Franka Emika FR3 로봇 팔 대상. 복잡한 플래닝 문제를 하위 태스크로 분해 후 transfer learning + reward redesign 조합으로 훈련 효율 향상. 실제 로봇 검증 포함.

### 주목할 최근 논문 [catch-up]

- **[SIPP on Lattices: Path Planning with Motion Primitives in Dynamic Environments](https://arxiv.org/abs/2609.31803)** — arXiv:2609.31803, 제출 2026-09-25, ICR 2026 채택
  - Safe Interval Path Planning을 사전 계산된 모션 프리미티브 기반 state lattice에 적용. 동적 장애물이 많은 환경에서 완전성·최적성 보장. 창고 로봇·자율주행 적용 시나리오에 적합.

- **[Risk-Aware Motion Planning with Learned Trajectory Primitives](https://arxiv.org/abs/2607.26802)** — arXiv:2607.26802, 제출 2026-07-29, IEEE ITSC 2026
  - 도심 주행 대상. 학습된 jerk-최소 궤적 프리미티브와 MPC를 결합하고 확률론적 위험도 측정을 추가. 불확실한 도심 환경에서의 안전한 AV 플래닝에 직접 연결되는 접근법.

- **[Re4MPC: Reactive Nonlinear MPC via Deep RL](https://arxiv.org/pdf/2506.08344)** — arXiv:2506.08344, 2026-06월 [catch-up]
  - MPC의 물리 기반 예측과 RL의 정책 유연성을 결합한 Multi-model 반응형 MPC. 휴머노이드 로코모션 및 조작 태스크에서 RL 단독보다 성능·제약 처리 모두 우수.

### OSS / 산업 동향

- **Isaac ROS 5.0** (2026-09, ROSCon Toronto 발표): 로보틱스 개발 에이전틱(agentic) 워크플로우 추가, ROS Lyrical 지원. 조작 태스크 자동화를 위한 Isaac Skills 모듈 포함. Nav2와의 통합 포인트 확장으로 복잡한 미션 플래닝 파이프라인 구축 편의성 증가.

## 3. 3D Reconstruction / Scanning

### 신규 논문 (arXiv) — 이번 주

- **[3D Gaussian Splatting within Self-Learned Neural View-Dependent Color Fields](https://arxiv.org/html/2611.03114)** — arXiv:2611.03114, 제출 2026-11월 초
  - 3DGS에 view-dependent color를 self-supervised 뉴럴 필드로 학습시키는 방법. 사전 컬러 가정 없이 specular/non-Lambertian 표면을 더 충실히 재현. 기존 3DGS 파이프라인에 플러그인 형태로 추가 가능.

- **[Quo Vadis, Driving Scene Reconstruction? Occlusion-Aware Gaussian Densification](https://arxiv.org/abs/2611.06273)** — arXiv:2611.06273, 제출 2026-11-04
  - 자율주행 장면 feed-forward 3DGS에서 관측이 부족한 가림 영역에 Gaussian을 능동적으로 추가해 완성도를 높이는 기법. 차량 간 가림으로 인한 복원 공백 문제를 체계적으로 접근한 최초 연구 중 하나로, HD 맵 생성 품질에 직접 영향.

### 주목할 최근 논문 [catch-up]

- **[Leveraging NeRF-Rendered Images for 3D Gaussian Splatting (ICIP 2026)](https://arxiv.org/abs/2606.09034)** — arXiv:2606.09034, 2026-06월
  - 사전 학습된 도시 NeRF로 훈련 이미지를 보완한 뒤 3DGS를 학습. NeRF의 화질과 3DGS의 렌더링 속도를 동시에 취하는 하이브리드 전략. 도로·건물 등 대규모 장면 재건에서 데이터 부족 문제 완화.

- **[D3GS: Depth, DINO, RGB Diffusion Co-Guided 3DGS for Sparse-View Reconstruction](https://arxiv.org/abs/2609.22941)** — arXiv:2609.22941, 2026-09월
  - Sparse view(소수 입력 뷰)에서 diffusion 기반 메트릭 depth completion → DPT 정제 → Gaussian 초기화 파이프라인. DINO semantic feature를 추가 가이드로 사용해 기하학적 정합도 향상. 모바일 3D 스캐닝 현장화에 적합한 접근.

### OSS / GitHub

- **GSPrior (CVPR 2026)** — [GitHub takeshie/GSPrior](https://github.com/takeshie/GSPrior): Self-constrained prior를 활용한 고품질 표면 재건 3DGS. CVPR 2026 채택, 코드 공개. 정밀 제조·문화재 디지털화 활용 기대.
- **COLMAP 4.3.0.dev0** — 개발 빌드 2026-11-01 기준 존재. 공식 릴리즈 시 LoMa learned matching과 GPU BA 개선사항이 포함될 것으로 예상. 릴리즈 주시.

### 블로그 / 산업 동향

- **Waymo Custom ASIC 공개 (2026-08, catch-up):** 5nm 공정 목적 특화 칩, 1,000+ TOPS ML 성능. 실시간 고밀도 LiDAR 포인트 클라우드 처리 + 3D 장면 재건을 단일 온보드 칩에서 수행. 자율주행 차량 내 실시간 3D reconstruction의 하드웨어 경쟁을 가속화하는 신호.
