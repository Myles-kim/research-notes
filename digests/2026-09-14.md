## 1. LiDAR SLAM / Sensor fusion

### 신규 논문 (arXiv)

- **LightSplat: Real-Time High-Fidelity 3D Gaussian SLAM with Loop Closure** — Junze Bao et al. arXiv:2609.07274
  - 3D Gaussian Splatting 맵 표현 위에 루프 클로저를 통합한 실시간 SLAM. IROS 2026 채택. 기존 GS-SLAM 계열이 루프 클로저를 생략하거나 별도 최적화로 처리했던 한계를 정면 돌파한 점이 의미 있다.

- **Functional-SLAM: Interaction-Aware Mapping with Online Functional Scene Graphs** — arXiv:2609.07497
  - 온라인으로 구축되는 기능적 씬 그래프(Functional Scene Graph)를 SLAM에 통합하여 물체 간 인터랙션 관계를 맵에 인코딩. 로봇 작업 계획과 의미론적 SLAM의 접점에 위치한 흥미로운 시도.

- **[catch-up] Ultra-Fusion: A Resilient Tightly-Coupled Multi-Sensor Fusion SLAM Framework** — arXiv:2606.21223
  - WIO·VIO·LIO·LVIO를 통합 슬라이딩 윈도우 추정기로 처리하며, GNSS·휠 오도메트리까지 선택적으로 융합. ITS(지능형 교통 시스템) 환경에서 LiDAR 퇴화, 조명 불량, GNSS 단절 등 복합 센서 열화에 강인함을 실증. 코드 공개: [github.com/sjtuyinjie/Ultra-Fusion](https://github.com/sjtuyinjie/Ultra-Fusion)

- **[catch-up] SA-LIVO: Efficient LiDAR-Inertial-Visual Odometry with Subspace-Aware Degeneracy Handling** — arXiv:2606.25699
  - LiDAR 퇴화(평탄한 복도, 개방 공간) 상황에서 서브스페이스 분석으로 퇴화 방향을 감지해 IMU·카메라로 보완하는 경량 LIVO 시스템. 계산 효율과 강인성을 동시에 확보.

### OSS 릴리즈 / GitHub trending

- **2DGS-SLAM** (PRBonn/2DGS-SLAM) — TRO 2026 게재 확정으로 코드 공개
  - 2D Gaussian Splatting을 RGB-D SLAM 맵 표현으로 사용. 깊이 일관성 렌더링을 통해 기하학적으로 정확한 전역 맵 재구성 달성. 기존 3DGS-SLAM 대비 표면 품질 및 글로벌 일관성 우수.

### 블로그 / 산업 동향

- **NVIDIA Physical AI 플랫폼**: NVIDIA는 2026년 초 발표한 GR00T 오픈 모델과 Isaac Lab-Arena, OSMO 엣지-클라우드 프레임워크를 기반으로 로봇 학습 파이프라인 생태계를 급속히 확장 중. Isaac ROS의 nvBlox → Nav2 연동 워크플로우가 LiDAR 기반 맵 → 경로 계획 통합 레퍼런스로 자리잡고 있다.

## 2. Path planning / Motion planning

### 신규 논문 (arXiv)

- **Dual Process Motion Planning** — Jiayi Yan, Francesco Fabiano, Alessandro Abate. arXiv:2609.01260 (2026-09-01)
  - Kahneman의 "빠른 직관(System 1) + 느린 추론(System 2)" 이분법에서 착안. 심볼릭 솔버(System 2)와 경험 기반 학습 모듈(System 1)을 메타인지 컨트롤러가 동적으로 조율하는 뉴로-심볼릭 비선형 모션 플래닝 프레임워크. 계산 효율과 안전 보장 간 트레이드오프를 런타임에서 적응적으로 조정한다는 점이 신선하다.

- **[catch-up] Learning-Based Motion Planning for Dynamic Environments: From Foundational Algorithms to Emerging Paradigms** — Zongyuan Shen et al. arXiv:2608.00625 (2026-08-01)
  - 2015~2025년 대표적 학습 기반 모션 플래닝 연구를 종합하는 서베이. "학습이 플래닝 파이프라인에서 어떤 역할을 하는가"라는 분류 체계(직접 정책 학습 / 학습 보강 고전 계획 / 하이브리드)를 제안. 자율주행·서비스 로봇·다중 로봇 시스템 등 폭넓은 응용 커버.

- **[catch-up] Coverage Path Planning: Classical Foundations, Recent Advances, and Future Directions** — arXiv:2607.10649 (2026-07-12)
  - 125편의 대표 논문을 포괄하는 커버리지 경로 계획 서베이. 단일 로봇 → 다중 로봇, 2D → 3D 환경, 학습 기반 커버리지까지 최신 트렌드를 체계적으로 정리. 드론 매핑·농업 로봇 분야 실무자에게 유용한 레퍼런스.

- **Interactive Trajectory Planning with Learning-based Distributionally Robust MPC** — arXiv:2605.07768 (2026-05-08)
  - [catch-up] 주변 에이전트의 의사결정 불확실성을 PAC 학습으로 추정하고 DR-MPC(분포 강건 MPC)로 인터랙티브 경로 계획을 수행. 로버스트 MPC와 전능 SMPC 사이를 샘플 수에 따라 보간하는 수식적으로 우아한 프레임워크.

### OSS 릴리즈 / GitHub trending

- **The Open Motion Planning Library (OMPL) 2.0** — arXiv:2605.29301 [catch-up]
  - 오랫동안 유지·발전해온 OMPL의 메이저 버전 2.0이 논문으로 정리됨. 새로운 API, 파이썬 바인딩 개선, 병렬 플래너 지원 등 포함. ROS 2 / Nav2 생태계와의 연동 기준점.

## 3. 3D Reconstruction / Scanning

### 신규 논문 (arXiv)

- **AnyGS2Mesh: Feed-Forward Mesh Reconstruction from 3D Gaussian Splatting with Arbitrary-Resolution Views** — Yuxuan Song et al. arXiv:2609.03304 (2026-09-03)
  - 3DGS 표현으로부터 직접 고품질 3D 메시를 복원하는 최초의 feed-forward 프레임워크. Gaussian-Guided Transformer + Streaming Patchwise Depth Encoder + TSDF 융합 + Marching Cubes 파이프라인으로 구성. 최적화 기반 대비 추론 속도를 대폭 단축하며 임의 해상도 입력 처리 가능. 3DGS로 재구성한 씬을 다운스트림 시뮬레이션·렌더링에 바로 투입해야 하는 산업 파이프라인에 즉각적인 실용 가치.

- **STARS-GS: Structure-Aware Regularized Gaussian Splatting for Large-Scale Aerial Surface Reconstruction** — Bocheng Li et al. arXiv:2609.03447 (2026-09-03)
  - 항공 이미지 기반 대규모 3D 표면 재구성에 특화된 3DGS 프레임워크. 구조 인식 씬 분할로 연속적인 씬 요소가 서로 다른 서브-리전에 쪼개지는 문제를 완화하고, 경계 정제로 스티칭 아티팩트를 저감. GIS·도시 모델링·드론 측량 분야 직접 적용 가능성 높음.

- **RouteBridge: Reliability-Routed Bidirectional Distillation Between Neural Radiance Fields and 3D Gaussian Splatting** — YuanHang Wang, Xin Cao. arXiv:2609.09606 (2026-09-09)
  - NeRF와 3DGS의 상호 보완적 특성을 활용한 양방향 지식 증류 프레임워크. 광도 잔차 + 표현별 기하학적 증거를 결합한 신뢰도 추정기가 각 레이마다 NeRF→3DGS, 3DGS→NeRF, 또는 기권(abstain) 중 최적 교수 방향을 동적으로 선택. DTU 3-view 벤치마크 21.12 dB 달성.

- **[catch-up] Splaxel: Efficient Distributed Training of 3D Gaussian Splatting for Large-scale Scene Reconstruction** — arXiv:2606.18588
  - 픽셀 수준 통신으로 대규모 씬 분산 학습을 가능하게 하는 3DGS 분산 훈련 기법. 단일 GPU로는 불가능한 초대형 씬 재구성 문제를 해결하는 엔지니어링 기여.

### OSS 릴리즈 / GitHub trending

- **COLMAP 4.2.0** (colmap/colmap) — 2026-08-31 릴리즈
  - **멀티 컴포넌트 글로벌 매핑**: 뷰 그래프의 비연결 컴포넌트 각각을 독립 모델로 재구성. 기존 최대 컴포넌트 하나만 유지하던 한계를 극복. `GlobalMapper.multiple_models` 플래그로 제어.

  - **AMD ROCm/HIP 지원**: `patch_match_stereo` 단계에서 AMD GPU 가속 가능.
  - **브라우저 기반 3D 뷰어**: 로컬 온리 희소 재구성 시각화 도구 내장.
  - 포토그래메트리·NeRF·3DGS 전처리 파이프라인 모두에 직접 영향을 주는 중요 업데이트.
